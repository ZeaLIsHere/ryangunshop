# RyanGunshop — Panduan dan status aksesibilitas

Status: **19 November 2026**, acuan kode `a85a159`. Dokumen ini menetapkan sasaran aksesibilitas dan
mencatat bukti pengujian yang tersedia, **bukan sertifikasi WCAG atau audit
TalkBack/perangkat Android yang sudah tuntas**. Denah/panorama berstatus arsip.

## Layout, teks, dan sentuhan

- Sasaran minimum: lebar **360 dp**, text scale **1.3**, target sentuh **48×48 dp**.
  Konten harus dapat digulir; teks, harga, dan tindakan tidak boleh tertutup.
- Produk memakai grid baris lazy melalui `CustomScrollView`/
  `SliverList.builder`: dua kolom pada 360 dp, tiga pada 600 dp, lima pada
  1024 dp dalam pengujian. Kartu mengikuti tinggi konten alami, bukan aspect
  ratio tetap. Nama/barcode/harga panjang dan skala 1.3 termasuk kasus regresi.
- Judul **Produk** tanpa tag **Tersimpan di perangkat**. Hilangnya tag tidak
  boleh ditafsirkan sebagai status cloud.
- Beranda kasir mempertahankan desain operasional asli; Beranda pemilik memakai
  hierarki analitik periode Hari ini/7 hari/30 hari. Hero, pod aksi, baris nota,
  dan enam Pintasan Menu memakai `dashboard_components.dart` bersama.
- Pintasan kedua peran mencakup Katalog produk, Keranjang, Riwayat transaksi,
  Pengaturan, Statistik, Chatbot. Pengujian regresi mencakup gulir, callback,
  aset/label, dan target sentuh pada 360 dp/skala 1.3.

## Kontras dan makna status

Identitas tetap violet `#7C3AED`, ink `#0F172A`, muted `#64748B`, canvas
`#FAF8FE`, surface `#FFFFFF`; ambil dari token tema, bukan literal widget.
Perhitungan pasangan warna dan batas pemakaian tersedia di `COLOR_PALETTE.md`.

Rasio teks utama dan tombol bukan bukti seluruh layar patuh WCAG. Warna dasar
success/warning/error di atas putih **tidak mencapai 4.5:1 untuk teks normal**;
gunakan pasangan teks/latar yang diuji, bukan warna status dasar sebagai teks
kecil. Periksa juga opacity, gradien, ukuran huruf, dan state nonaktif.

Status selalu membutuhkan **ikon dan teks**, bukan warna saja:

- Stok: tersedia/menipis/habis, berdasarkan stok repository.
- Sinkronisasi: offline/mengantre/tersinkron hanya sesuai bukti. SDK siap bukan
  unggah berhasil; outbox kosong bukan bukti backfill produk lama.
- Pembayaran: tunai berhasil setelah simpan SQLite berhasil. QRIS masih kontrak
  tampilan/simulasi, tidak boleh diumumkan sebagai pembayaran nyata.
- Data sintetis yang diimpor untuk presentasi tidak diberi label visual
  contoh/sintetis/demo. Asal data tetap tercatat internal; aturan ini tidak
  mengubah kejelasan status stok, pembayaran, atau sinkronisasi.

## Semantik, kamera, dan gerakan

- Ikon tanpa label universal wajib tooltip/label semantik yang menjelaskan aksi.
  Periksa urutan fokus, angka rupiah, kuantitas, dan pengumuman status dinamis
  dengan TalkBack pada perangkat; belum ada bukti audit manual lengkap.
- Kamera `mobile_scanner` memiliki fallback input/pencarian manual. Pengguna
  tetap perlu mengonfirmasi produk; kamera dilepas selama checkout dan
  disiapkan ulang saat pemindaian berikutnya. Uji izin ditolak serta pemulihan.
- Splash memakai signature motion sekitar 1,45 detik dan crossfade 280 ms;
  `disableAnimations` menghasilkan transisi instan. Onboarding menyediakan
  reduced motion. Sasaran ini perlu pemeriksaan pada perangkat, bukan hanya
  keberadaan assertion widget.
- Peran pemilik/kasir dari Pengaturan bukan autentikasi. Kontrol tersembunyi
  atau dinonaktifkan tidak boleh didokumentasikan sebagai keamanan login.

## Monitor — kriteria penerimaan rencana, belum diuji

Acuan kanonis: [Rencana Monitor](monitor-plan.md). Tombol Beranda khusus pemilik
membuka halaman baru; komponen `floor_plan` arsip hanya kandidat reuse setelah
audit, bukan bukti Monitor sudah tersedia atau lolos uji.

- Kanvas isometrik 2.5D harus memiliki **daftar aksesibel** dengan fungsi setara:
  memilih fixture, membaca produk/stok, dan melakukan aksi editor tanpa drag.
  `CustomPainter`/`InteractiveViewer` kandidat, bukan pengganti semantik native.
- Nama semantik fixture menyebut jenis, nama, jumlah jenis produk, serta jumlah
  jenis menipis/habis. Jangan menjumlah unit stok campuran. Status memakai ikon
  dan teks; stok/ambang berasal dari produk, bukan salinan pada fixture.
- **Pantau** tidak menerima gesture pemindahan. **Edit** mempunyai kontrol
  tambah/pindah/nama/rotasi 90°/hapus yang dapat dioperasikan tanpa gesture
  presisi, target minimal 48×48 dp, Simpan/Batal, dan penjaga keluar saat kotor.
  Penghapusan rak dijelaskan sebagai pelepasan produk, bukan penghapusan produk.
- Setup tiga template (Dinding, Dua baris, Dinding + tengah), penempatan massal
  berkonfirmasi manual, dan pilihan melewati produk harus terbaca TalkBack.
  Kelompok **Belum ditempatkan** tetap dapat diakses.
- Detail berupa bottom sheet ponsel/panel samping tablet, konten dapat digulir,
  fokus masuk/keluar teratur. Uji lebar 360 dp, skala teks 1.3, keyboard terbuka,
  teks panjang, target 48 dp, dan tidak ada aksi tertutup.
- Reset zoom berlabel, pan/zoom tidak wajib untuk membaca data. Reduced motion
  meniadakan animasi nonesensial; tidak ada gerak terus-menerus untuk peringatan.
- Uji state kosong/memuat/error/offline dan cache usang. Jangan mengumumkan stok
  cloud terkini saat hanya cache tersedia. Baca publik HTTP 200 dan stok
  last-write-wins bukan jaminan keamanan atau stok serentak lintas perangkat.

## Pemeriksaan berikutnya

1. Ulangi pengujian otomatis dari `mobile/`:

   ```bash
   flutter analyze --no-pub
   flutter test --no-pub --reporter expanded
   flutter test --no-pub test/features/accessibility_audit_test.dart
   ```

2. Pada Android 360 dp/skala 1.3, periksa kedua Beranda, seluruh pintasan, Produk,
   formulir, kamera/manual, keranjang, pembayaran, laporan, dan chatbot.
3. Gunakan TalkBack, font besar, keyboard terbuka, dan reduced motion. Ukur
   target sentuh dan kontras komposit aktual, termasuk error/offline/kosong.
4. Catat perangkat, build, langkah, serta hasil aktual. Sampai ada bukti itu,
   jangan menandai seluruh layar atau alur Android sebagai lulus audit fisik.
