# RyanGunshop — Panduan dan Audit Aksesibilitas

Dokumen ini mendokumentasikan hasil audit aksesibilitas (A11y) antarmuka RyanGunshop,
sesuai dengan prinsip desain pada `DESIGN.md` dan standar WCAG 2.1 Level AA serta
pedoman aksesibilitas Android.

Audit ini memastikan aplikasi dapat digunakan secara andal pada perangkat kelas bawah,
layar kecil (lebar 360 dp), pembesaran teks sistem (text scale 1.3), serta bagi pengguna
yang mengandalkan pembaca layar (TalkBack) atau preferensi reduced motion.

---

## 1. Skala Teks (Text Scale 1.3) dan Layar Sempit (360 dp)

### Prinsip Layout Responsif
- **Lebar minimum:** Semua tata letak dirancang untuk tetap utuh pada lebar viewport 360 dp
  tanpa ada teks yang terpotong secara destruktif (*overflow* atau *clipped*).
- **Pembesaran teks:** Pada skala teks 1.3× (pengaturan aksesibilitas font besar di Android),
  kontainer vertikal menggunakan `SingleChildScrollView` atau `ListView` agar konten tetap
  dapat digulir dan tombol tindakan di bagian bawah tetap terjangkau.
- **Wrap & Flex:** Elemen bersebelahan seperti badge status, harga, dan tombol aksi
  menggunakan `Wrap` atau kolom adaptif ketika ruang horizontal tidak mencukupi.

### Hasil Audit Layar Utama

| Layar / Komponen | Perilaku pada 360 dp & Text Scale 1.3 | Status |
|---|---|---|
| **Splash Screen** | Logo dan teks status tetap berada di tengah layar tanpa overflow | Lulus |
| **Onboarding** | Carousel tiga halaman dengan ilustrasi proporsional; tombol lewati dan lanjut tetap terlihat | Lulus |
| **Dashboard Bento** | Aksi utama dan shortcut tertata rapi; kartu ringkasan menyusut tanpa memotong angka | Lulus |
| **Denah (`StoreFloorPlan`)** | Kanvas dapat di-pan/zoom secara bebas; label teks pada fixture disesuaikan | Lulus |
| **Katalog Produk** | Kartu produk menyusun baris informasi secara vertikal bila nama panjang | Lulus |
| **Formulir Produk** | Satu kolom terstruktur; tombol simpan menempel aman di bawah keyboard | Lulus |
| **Pemindai Produk** | Panel hasil di bawah kamera tetap menampilkan ringkasan produk dan tombol konfirmasi | Lulus |
| **Keranjang & Checkout** | Stepper kuantitas dan total sticky bawah tetap terpisah dan mudah ditekan | Lulus |
| **Sheet Pembayaran** | Pemilihan Tunai/QRIS dan tombol hitung kembalian dapat digulir jika ruang terbatas | Lulus |

## 2. Ukuran Target Sentuh (Minimum 48×48 dp)

Sesuai pedoman Material Design dan Android Accessibility:
- Setiap elemen interaktif memiliki bidang sentuh (*touch target*) minimal **48×48 dp**,
  meskipun ukuran visual ikon atau teks lebih kecil.
- Padding internal (`EdgeInsets`) atau `BoxConstraints(minWidth: 48, minHeight: 48)`
  diterapkan pada kontrol kecil seperti tombol penutup, stepper (+/-), chip filter,
  dan tombol kontrol mode edit denah.

### Evaluasi Komponen Interaktif

| Komponen | Target Sentuh Visual | Bidang Sentuh Aktual | Status |
|---|---|---|---|
| `PrimaryAction` | Tinggi 48–52 dp, lebar penuh | Lebar layar × 48+ dp | Lulus |
| Tombol Tab Navigasi Bawah | Tinggi 56 dp | 1/4 lebar layar × 56 dp | Lulus |
| Stepper Keranjang (+ / -) | Ikon 20 dp | 48×48 dp (dengan padding) | Lulus |
| Kontrol Edit Denah (Putar, Ukuran, Duplikat, Hapus) | Ikon 20 dp | 48×48 dp per tombol | Lulus |
| Chip Filter & Kategori | Tinggi visual 36 dp | Tinggi hit-test 48 dp | Lulus |
| Tombol Senter Pemindai | Ikon 24 dp | 48×48 dp | Lulus |
| Tombol Tutup Bottom Sheet | Ikon 24 dp | 48×48 dp | Lulus |

## 3. Kontras Warna dan Penanda Non-Warna

### Kepatuhan Kontras WCAG 2.1 Level AA
Berdasarkan `docs/COLOR_PALETTE.md`:
- Teks utama (`AppColors.ink` `#191A2E`) di atas `AppColors.canvas` (`#F7F7FB`) memiliki rasio kontras **≥ 15:1** (jauh melampaui ambang batas minimum 4.5:1).
- Teks pendukung (`AppColors.muted` `#62657A`) di atas `AppColors.surface` memiliki rasio kontras **≥ 5.5:1**.
- Teks tombol utama (`AppColors.surface` `#FFFFFF`) di atas `AppColors.primary` (`#565C9D`) memiliki rasio kontras **≥ 6:1**.

### Prinsip Penanda Non-Warna (Color Blindness Friendly)
Informasi status sistem dan data tidak pernah disampaikan melalui warna saja:
1. **Status Stok:**
   - Stok Cukup: Latar hijau muda + Ikon centang (`Icons.check_circle_outline`) + Teks "Tersedia".
   - Stok Menipis: Latar jingga muda + Ikon peringatan (`Icons.warning_amber_rounded`) + Teks "Menipis (< N)".
   - Stok Habis: Latar merah muda + Ikon silang/blokir (`Icons.cancel_outlined`) + Teks "Habis".
2. **Status Sinkronisasi (`SyncPill`):**
   - Offline: Ikon awan terputus (`Icons.cloud_off`) + Teks "Offline".
   - Mengantre: Ikon putar antrean (`Icons.sync`) + Teks "Menunggu sinkronisasi".
   - Tersinkron: Ikon awan tercentang (`Icons.cloud_done`) + Teks "Tersinkron".
3. **Status Pembayaran QRIS:**
   - Menggunakan teks status eksplisit (`Menyiapkan`, `Menunggu Pembayaran`, `Berhasil`, `Kedaluwarsa`, `Gagal`) disertai ikon status pendukung.

## 4. Pembaca Layar (Semantics & TalkBack)

Semua elemen visual penting diberi label semantik untuk navigasi tunanetra atau pembaca layar:

- **Objek Denah (`FixtureTile`):**
  Menggunakan `Semantics(label: "...", button: true)` dengan format deskriptif:
  `"[Nama Objek], Rak [Tipe], berisi [N] produk. Ketuk untuk melihat daftar produk."`
- **Mode Switch Denah:**
  Mengumumkan mode aktif dan status ketersediaan: `"Mode denah dua dimensi, terpilih"` atau `"Mode panorama 360 derajat, tidak tersedia"`.
- **Ikon Non-Universal:**
  Semua tombol berbasis ikon (tanpa teks langsung) memiliki properti `tooltip` dan deskripsi semantik:
  - Tombol senter: `"Nyalakan lampu kilat"` / `"Matikan lampu kilat"`
  - Tombol putar denah: `"Putar objek 90 derajat searah jarum jam"`
  - Tombol duplikat denah: `"Duplikasi objek"`
  - Tombol hapus objek: `"Hapus objek denah"`
  - Tombol tutup sheet: `"Tutup"`

---

## 5. Preferensi Gerakan Minimal (Reduced Motion)

Aplikasi menghormati preferensi `disableAnimations` dan `MediaQuery.of(context).disableAnimations`:
- **Splash Screen:** Signature motion 1,45 detik dilewati secara instan jika animasi dinonaktifkan, langsung membuka onboarding atau dashboard.
- **Carousel Onboarding:** Transisi antar halaman menjadi instan tanpa efek geser berlebihan.
- **BrandSpinner & Indikator Memuat:** Menggunakan ikon statis dan pesan teks ketika mode gerakan minimal aktif.
- **InteractiveViewer (Denah):** Mencegah efek transisi zoom yang memusingkan, mempertahankan titik fokus yang stabil.

Pemeriksaan aksesibilitas diverifikasi secara berkala lewat test otomatis di `mobile/test/`:
- `test/features/catalog/catalog_test.dart` (uji 360 dp dan skala teks 1,3)
- `test/features/floor_plan_test.dart` (uji semantik dan ukuran kontrol denah)
- `test/features/accessibility_audit_test.dart` (uji komprehensif audit aksesibilitas)

Semua pengujian dapat dijalankan kapan saja dengan:
```bash
cd mobile
flutter test test/features/accessibility_audit_test.dart
```
